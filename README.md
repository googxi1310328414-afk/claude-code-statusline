# claude-code-statusline

Claude Code 的信息密集型彩色状态栏（Windows / Git Bash），三行主题式布局 + 子代理面板行接管。数据缺失的段自动隐藏，整行为空时该行消失；关键指标随状态动态变色。

```
07:49:00 | Fable 5·max·think | ~\claude-code-statusline | main*
ctx ████░ 71% 294k/1M | ▂▃▂▄ 2.9k/m | cache 99%
$74.94 $79.8/h | +2005/-585 | 5h 32%→09:10 7d 12%→08-15 | » 会话名
```

- **第 1 行 · 身份与位置**：秒级时钟 | 模型·思考档位·think | 目录缩写 | ⎇worktree | 仓库 | 分支+脏标记 | PR
- **第 2 行 · 上下文引擎**：`ctx` 电池条（实际占用=输入+输出）| token 走势▁▂▄▇+速率 | 缓存命中率
- **第 3 行 · 开销与限额**：花费+$/h 速率 | 代码行增减 | 5h/7d 限额+重置时间 | » 会话名

新会话数据薄时自动缩成一两行。

## 主状态栏 14 段

| 行 | 段 | 内容与颜色 |
|---|---|---|
| 1 | 时钟 | `HH:MM:SS` 亮白（事件驱动刷新，空闲时不走秒） |
| 1 | 模型 | 名称亮青 · 思考档位热度渐变（low灰/medium绿/high黄/xhigh亮紫/max亮红）· `think` 紫 |
| 1 | 目录 | 主目录→`~`、深路径折叠 `首\…\尾两级`；父路径蓝+末级亮蓝 |
| 1 | worktree | `⎇ 名称→分支`（仅 --worktree 会话；亮蓝/灰/绿） |
| 1 | 仓库 | `owner/name`：青/灰/亮青 |
| 1 | 分支 | 名称恒绿 + 未提交改动 `*` 黄 |
| 1 | PR | `PR#N` 紫 + 状态动态色（approved绿/changes_requested亮红/待审黄/草稿灰） |
| 2 | 上下文 | `ctx` 灰标签 + 五格电池 + 百分比（≥50%绿/20–49%黄/<20%亮红带`!`）+ `占用/窗口`（白/灰，≥1000k 显示为 M，如 `294k/1M`）。**占用=输入+最新输出**，比官方 input-only 口径更接近真实 |
| 2 | 走势+速率 | 青色 ▁▂▄▇（跨刷新历史推导）+ `2.3k/m`（<5k灰/5–15k黄/≥15k亮红） |
| 2 | 缓存 | `cache N%` 命中率（≥80%绿/50–79%黄/<50%亮红），由 current_usage 计算 |
| 3 | 花费 | `$`无色 + 金额（<$1灰/$1–4黄/≥$5亮红）+ `$X.X/h` 速率（同阈值） |
| 3 | 行数 | `+A`绿`/`-R`红 |
| 3 | 限额 | `5h`/`7d` 青标签 + 百分比动态色（<50绿/50–79黄/≥80亮红）+ `→重置`白（5h 显时刻、7d 显日期） |
| 3 | 会话名 | `» 名称` 灰 |

走势、速率、$/h 依赖状态文件 `~/.claude/statusline-history.tsv`（每次刷新追加一行会话占用/花费快照，同会话 5 秒去重，保留 200 行，损坏行自动跳过）。

## 子代理面板行（subagentStatusLine）

底部主状态栏永远显示主会话数据（官方无跟随子代理视图的机制）；代理面板中每个子代理行则由 `subagent-statusline.sh` 完全接管：

```
▸ code-reviewer(general)·max ● | ███░░ 66% 68k/200k | ▄█▁▁ 10.5k/m | Σ12% | 6m27s@07:43:07 | Review the auth…
▸ researcher ✓ | 12k tok | 131/m | Σ2% | 1h31m2s@06:18:34 | Find docs
▸ verify:auth·haiku-4-5·50000 ✗ | █████ 447k tok | █▁▄ 248.3k/m | Σ84% | 1m48s@07:47:49 | Adversarial verify…
```

- 灰 `▸` + **亮紫**名称（主状态栏身份是亮青，主/子一眼区分）+ 灰`(类型)` + 青·少数派模型（仅当与面板多数模型不同，自动剥 `claude-` 前缀和日期后缀）+ 热度·档位（仅显式指定时）+ 状态图标（`●`运行绿 / `○`排队黄 / `✗`失败亮红 / `✓`完成绿 / `?`未知黄）
- 电池条：`tokenCount ≤ 窗口`时近似上下文占用；**超过窗口即累计消耗**，改红满条 `█████ 447k tok` 不再显示百分比
- 走势（tokenSamples 防御式解析，数字/对象两种形态均可）+ 速率合为一段，与主行第 2 行对齐
- `ΣN%`：该行占面板全部子代理 token 总量的份额（≥75% 亮红揪出吞金兽）
- 秒级用时 `6m27s@07:43:07`（毫秒/秒时间戳自适应）+ 按面板宽度截断的灰色描述
- 机制：stdin 一次收到 `{"columns":N,"tasks":[…]}`，对每行输出一条 `{"id":…,"content":…}` JSON；无 id 的行保持默认渲染

## 依赖与安装

依赖：Claude Code（电池需 ≥2.1.205，effort 字段需 ≥2.1.214）、Git Bash（bash ≥4，UTF-8 locale）、`jq`、`git`。

1. 两个 `.sh` 复制到 `~/.claude/`。
2. **改主目录**：`statusline-command.sh` 中 `home_bs`/`home_fs` 两行硬编码了 `C:\Users\Administrator`，换成你的。
3. `~/.claude/settings.json` 合并 `settings-snippet.json` 的两个键（勿覆盖其他配置）。保存即生效。

### 让 AI 替你装（推荐）

把 [`AI-GUIDE.md`](AI-GUIDE.md) 全文发给 Claude Code，说"按这份指导配置状态栏"——完整规格、阈值、健壮性要求和验证清单都在里面。

## 已知边界与移植注意

- 状态栏刷新是**事件驱动**（约 300ms 防抖）：空闲时秒钟不走、内容静止，是宿主机制而非故障。
- `date -d "@epoch"` 是 GNU 语法；macOS/BSD 改 `date -r`。
- **Windows jq 输出 CRLF**：凡 `mapfile`/逐行读 jq 输出必须 `| tr -d '\r'`（`$(...)` 命令替换在 MSYS bash 下会剥尾部 `\r`，mapfile 不会——本仓库已全部防御）。
- 状态文件与多会话并发共享，行级损坏/竞争自动跳过，最坏丢几行采样。
